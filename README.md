# Eatake

**撮るだけで続くAI食事記録アプリ**

Eatake は、食事記録を続けたいけれど、細かい入力が面倒で続かない人に向けたAI食事管理アプリです。  
「完璧な記録」よりも「続く記録」を重視し、写真・成分表示・文面・手入力の複数の入口から、できるだけ少ない操作で食事ログを残せるようにしています。

このwebアプリはSAJ B Sports(https://archive.saj.or.jp/aibcf2026/)
のAIサービス開発部門に提出した作品になります
- Demo: https://eatake.onrender.com/

## AIビジネスコンテスト提出用

Eatake は、AIビジネスコンテスト提出用に制作したプロトタイプです。

目的は、審査員に以下の価値を伝えることです。

> 食事記録は、面倒だから続かない。  
> Eatake は、AIを使って入力の負担を減らし、ライト層でも食事管理を続けやすくするアプリです。

---

## 作った理由

自分自身、既存の食事管理アプリでは食事記録を継続できませんでした。

既存アプリでは、料理名を検索したり、量を調整したり、バーコードを読み取ったりする必要があります。  
バーコード入力も便利ではありますが、商品が登録されていない場合は結局1から入力する必要があり、毎日の記録としては手間が残ります。

食事管理は、正確さも大切ですが、まず続かなければ意味がありません。  
そこで Eatake では、正確さ100点の記録よりも、毎日続けられる60点の記録を重視し、継続しやすいダイエット・健康管理アプリを目指しました。

---

## 解決したい課題

健康管理やダイエットでは、食事記録が重要です。  
しかし、多くの人は以下のような理由で継続できません。

- 料理名検索が面倒
- 食事量の入力が難しい
- カロリーやPFCの調整が手間
- 毎食入力する心理的ハードルが高い
- 忙しい日は記録を忘れやすい
- 一度途切れると再開しづらい

特にライト層にとっては、最初から厳密な栄養管理をすることよりも、まず記録を残し続けることが重要だと考えました。

---

## Eatake のコンセプト

### 完璧な記録より、続く記録。

Eatake は、食事記録を「正確に入力する作業」ではなく、「軽く続けられる習慣」に変えることを目指しています。

- 写真を撮るだけで記録
- 写真が撮れない日は文面だけで記録
- 成分表示がある場合はAIで読み取り
- 数値が分かっている場合は手入力で補正
- 1日の記録をAIがやさしくレビュー

---

## 主なターゲット

Eatake は、細かい入力が苦手なライト層を主なターゲットにしています。

- ダイエット初心者
- 健康管理を始めたい人
- コンビニ食・外食が多い人
- 忙しい学生・社会人
- 筋トレや運動を始めたばかりの人
- 食事管理アプリを過去に挫折した人

---

## 主な機能

### 1. 食事写真からAIで栄養推定

食事写真を撮るだけで、AIが食事内容を推定し、以下の栄養素をざっくり記録します。

- カロリー
- タンパク質
- 脂質
- 炭水化物
- 糖質
- 食物繊維
- 塩分

最短2タップで記録できるようにし、入力の心理的ハードルを下げています。

---

### 2. 栄養成分表示の読み取り

食品パッケージに記載されている栄養成分表示を撮影すると、AIが数値を読み取り、記録に採用できます。

AIによる食事写真の推定は便利ですが、実際の食材量や商品によって数値に差が出る場合があります。  
成分表示がある商品では、表示されている数値を使うことで、推定のズレを減らせるようにしています。

---

### 3. 文面での食事記録

写真がない場合でも、短い文章から食事を記録できます。

例：

```text
おにぎり1個
ラーメン食べた
コンビニのサンドイッチ
```

AIが文面から食事内容を推定し、カロリーやPFCを概算します。  
写真を撮れなかった日でも、記録を止めないことを重視しています。

---

### 4. 成分手入力

AI推定に不安がある場合や、成分表示の数値が分かっている場合は、手入力で記録できます。

- 商品名・食事名
- カロリー
- タンパク質
- 脂質
- 炭水化物
- 糖質
- 食物繊維
- 塩分

AIに任せきりにせず、必要な時は自分で補正できるようにしています。

---

### 5. AIレビュー

1日の食事記録、PFC、日記、継続日数などをもとに、AIがその日の振り返りを作成します。

レビューでは、単に数値を指摘するだけではなく、継続を支える声かけを重視しています。

- 今日の振り返り
- よかった点
- 継続できた行動の評価
- 次に改善できること
- 明日への一言

---

## なぜ「褒めるAI」なのか

Eatake では、AIレビューを「責める」のではなく、「続けることを支える」方向に設計しています。

自分自身、食事管理が続かなかった経験があり、厳しすぎる管理はライト層にとって継続率を下げやすいと感じました。  
食事管理で一番大事なのは、短期間だけ完璧にやることではなく、ゆるく長く続けることです。

そのため Eatake では、達成できた日はしっかり褒め、うまくいかなかった日は責めるのではなく、次に何をすればよいかを提案するようにしています。

## AI活用ポイント

Eatake では、AIを「分析するため」だけではなく、「入力を楽にして継続を支えるため」に活用しています。

### 使用AI

- Gemini API
- さくらのAI Engine
- Codex

### 役割

| 使用AI | 主な用途 |
|---|---|
| Gemini API | 食事写真の画像解析、栄養成分表示の読み取り、文面からの食事推定 |
| さくらのAI Engine | AIレビュー生成 |
| Codex | 開発支援、実装補助、デバッグ補助 |

---

## さくらのAI Engineを使う理由

AIレビュー部分では、さくらのAI Engine API の無料枠を利用しています。

さくらのAI Engineを使うメリットは、以下の点にあります。

- 国産AIサービスであること
- 国内環境で処理できること
- 入力内容が学習利用されないこと
- OpenAI互換APIに対応していること
- 将来的に営利目的で始めた場合でも、OpenAI APIへ切り替えやすいこと

食事記録や生活習慣に関する情報は、ユーザーのプライベートに近い情報です。  
そのため、レビュー生成では、個人の生活習慣に近い情報を学習利用されずに扱えることを重視しています。

また、OpenAI互換APIを利用することで、プロトタイプ段階ではさくらのAI Engineを使い、将来的に商用化や大規模化が必要になった場合は、OpenAI APIへの移行負担を下げやすい構成を目指しています。

## 既存アプリとの差別化

従来の食事管理アプリは、「正確に入力すること」を前提にしているものが多いです。

一方で Eatake は、「雑でも記録が残ること」を重視しています。

| 比較項目 | 従来の食事管理アプリ | Eatake |
|---|---|---|
| 入力方法 | 検索・手入力中心 | 写真・成分表示・文面・手入力 |
| 記録の考え方 | 正確な入力を重視 | 継続しやすさを重視 |
| 写真がない日 | 記録しづらい | 文面だけでも記録可能 |
| AI推定のズレ | 手直しが必要 | 手入力で補正可能 |
| レビュー | 数値指摘が中心 | 継続を褒めるレビュー |
| 向いている人 | 管理に慣れた人 | 初心者・ライト層 |

## 使い方

### 1. 記録画面を開く

起動後、すぐに記録画面から始められます。

### 2. 記録方法を選ぶ

以下の4つの入口から選べます。

- 食事写真
- 成分表示解析
- 成分手入力
- 文面で残す

### 3. AI推定結果を確認する

AIがカロリーやPFCなどを推定します。  
必要に応じて、手入力で補正できます。

### 4. 記録する

「これで記録」を押すと保存されます。

### 5. レビュー画面で振り返る

1日の記録をもとに、AIが振り返りを作成します。

## 現在の公開状態

現在はプロトタイプ版として、ログインなしで利用できる設定にしています。

そのため、現時点では個人情報が写る写真のアップロードは避けてください。  
今後、ログイン機能やユーザーごとのデータ分離に対応する予定です。

---

## データとプライバシー

Eatake では、以下の情報を扱います。

- 食事写真
- 食事名
- カロリー、PFC、糖質、食物繊維、塩分
- 体重、身長、年齢、目的などの設定
- AIレビュー
- フィードバック内容

写真は表示用に圧縮して保存します。  
プロトタイプ版ではログインなしの共通領域に保存されるため、個人情報が写る写真の利用は避けてください。

設定画面から、すべての記録を削除できます。

---

## 栄養推定について

Eatake の栄養推定は、画像認識とAI推定による概算です。

実際の数値は、以下の要素によって変わります。

- 食材の量
- 調理方法
- 使用した調味料
- 商品ごとの栄養成分
- 写真の角度や明るさ

正確な数値が必要な場合は、栄養成分表示を撮影するか、手入力で補正してください。
